# cv_based_tree_measurement
Computer vision project assignment: automated tree mapping and measurement

This project implements a complete computer vision pipeline designed to detect, track, and measure trees in a video sequence, particularly with the aim of estimating their DBH (Diameter at Breast Height) and mapping their position in world coordinates. The system combines object detection, feature matching, camera pose estimation, 3D triangulation, ground segmentation, and visualization, leveraging classical and modern computer vision techniques.

The entry point of the system is the `main.py` script. It initializes all modules, loads the input video and calibration data, runs the detection and tracking pipeline for each frame, and handles all outputs such as the annotated video, top-down map, and CSV results file.

The YOLO-based tree detector is implemented in `tree_detector.py`. It uses a pretrained YOLOv8 model to identify trees in individual frames. Bounding boxes and confidence scores are extracted for all detections above a specified threshold. The bounding boxes are later used for tracking and measurement.

The module `tree_tracker.py` provides a simple but effective tracking approach using bounding box overlap measured via IoU (Intersection over Union). Each detection is either assigned to an existing track or given a new unique ID, enabling per-tree tracking across frames.

The file `depth_estimator.py` handles monocular depth estimation through pose estimation and triangulation. Using ORB features and essential matrix estimation, it computes relative camera motion between frames and triangulates 3D positions of tracked trees. This module also estimates the real-world translation scale from camera speed and frame rate assumptions.

To support DBH measurement, `dbh_calculator.py` analyzes the width of tree trunks in the image at a canonical height (1.3 meters above ground). It uses a combination of edge detection and projection calculations based on camera intrinsics and distance to the tree, derived from triangulation.

For isolating the ground region in each image, the `ground_segmenter.py` file provides a simple HSV-based segmentation technique that identifies typical road or ground colors. While basic, this segmentation is sufficient to localize the base of tree trunks for DBH estimation.

Visualization functionality is encapsulated in `visualizer.py`. This includes drawing bounding boxes, track IDs, and DBH annotations directly on the video frames, as well as maintaining a top-down map that shows the camera’s path and the 2D position of all detected trees in world coordinates.

Data output is managed by `utils.py`, which offers functions to initialize and write results to CSV. This includes frame-level metadata such as tree ID, 3D position, bounding box coordinates, and DBH measurements.

Lastly, `camera_calibration.py` provides a utility for loading camera intrinsic parameters and distortion coefficients from a file generated by a prior calibration process. These parameters are used across the system to ensure correct reprojection and 3D inference.

Each module is documented internally with Python docstrings and inline comments, making it straightforward to understand the responsibilities of each function and block of code. The system is designed for extensibility and debugging, with placeholders for more robust ground segmentation, scale estimation, and tracking mechanisms as needed.
